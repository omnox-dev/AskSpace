# 🐘 Neon Serverless PostgreSQL Setup Guide for AskSpace

Neon provides a **100% free lifetime PostgreSQL database** that never expires or deletes your data after 90 days. It automatically sleeps when inactive and wakes up in <1s when users access AskSpace.

The database schema is defined in [`prisma/schema.prisma`](file:///c:/Users/Om/Documents/Placement%20Cell/ask_questions/prisma/schema.prisma).

---

## 🚀 Step 1: Create a Free Database on Neon

1. Go to [**neon.tech**](https://neon.tech) and sign up for a free account.
2. Click **Create a project**.
3. Name your project (e.g. `askspace-db`) and select your region.
4. Click **Create Project**.
5. On the project dashboard, copy the **Connection string** (PostgreSQL URL). It looks like:
   ```text
   postgresql://username:password@ep-xyz.neon.tech/neondb?sslmode=require
   ```

---

## ⚡ Step 2: Push Database Schema to Neon

In your local project terminal (or using Prisma CLI), run:

```bash
npx prisma db push
```

This will automatically create all required tables (`Classroom`, `Question`, `AiQuestionSet`) in your Neon PostgreSQL database!

---

## 🌐 Step 3: Add `DATABASE_URL` to Vercel Environment Variables

1. Go to your Vercel Dashboard → Select your **AskSpace** project.
2. Navigate to **Settings** → **Environment Variables**.
3. Add a new variable:
   - **Key**: `DATABASE_URL`
   - **Value**: Your Neon Connection String from Step 1 (`postgresql://username:password@ep-xyz...`)
   - **Environment**: Select Production, Preview, and Development.
4. Click **Save** and trigger a **Redeploy** on Vercel.

---

## 🛡️ Database Schema Reference

The tables configured in [`prisma/schema.prisma`](file:///c:/Users/Om/Documents/Placement%20Cell/ask_questions/prisma/schema.prisma) are:

- **`Classroom`**: Stores private classroom codes, names, host PINs, active student counts, and lock statuses.
- **`Question`**: Stores student questions, upvote counts, author info, upvoter session IDs, status (`pending`/`answered`), and official host answers.
- **`AiQuestionSet`**: Stores AI-synthesized question sets and top confusions generated by Groq / Gemini.
